// ABOUT

A tactical reimagining of Tetris powered by a custom-built C++ game engine (SimpleEngine2D). Instead of real-time falling blocks, players strategically place pieces via a drag-and-drop deck management system.

// ENGINE PHILOSOPHY

Manual Memory (RAII) No garbage collector. Deterministic resource lifecycles using Smart Pointers and Value Semantics.
Cache Locality Data-oriented design. Contiguous memory allocation using std::array for the game board.
ECS Architecture Strict separation of data (Components) and logic (Systems) for an extensible foundation.
Decoupled Systems Type-safe EventBus architecture to broadcast line clears and state changes across the engine.

// CORE MECHANICS

Drag & Drop
Tactical placement instead of falling blocks

Manage 3 available pieces strategically
